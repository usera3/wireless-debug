wireless_debug 程序流程图

基于当前源码整理。页面内嵌两张总览图；同目录的 .mmd 文件包含更详细流程，可单独导入 Mermaid Live、draw.io 或其他支持 Mermaid 的流程图工具。

1. 启动初始化流程

文件：01_boot_sequence.mmd

flowchart TD
    A([ESP32-S3 上电 / app_main]) --> B[NVS 初始化]
    B --> C{NVS 分区可用?}
    C -- 否: NO_FREE_PAGES 或 NEW_VERSION --> C1[擦除 NVS]
    C1 --> C2[重新初始化 NVS]
    C -- 是 --> D[app_core_init
默认 UART=2Mbps
默认通信=AUTO]
    C2 --> D
    D --> E{CONFIG_ENABLE_BLE?}
    E -- 是 --> E1[ble_spp_transport_init
注册 BLE RX/ready/status/heap 回调]
    E -- 否 --> F[ui_controller_init]
    E1 --> F
    F --> F1[ui_controller_init
注册 WiFi/UART/BLE/heap 操作回调]
    F1 --> G{CONFIG_ENABLE_WIFI?}
    G -- 是 --> G1[esp_netif_init]
    G1 --> G2[esp_event_loop_create_default]
    G -- 否 --> H[启动 UART transport]
    G2 --> H
    H --> H1[uart_transport_start]
    H1 --> H2[安装 UART1 driver
TX GPIO10, RX GPIO9
RX/TX ring buffer 32KB]
    H2 --> H3[设置 RX timeout 和 RX full threshold]
    H3 --> H4[创建 uart_transport_task
负责事件读取和软件组帧]
    H4 --> I[display_port_init]
    I --> I1{SSD1315 I2C 探测成功?}
    I1 -- 是 --> I2[初始化 SSD1315 OLED
写入启动测试图案]
    I1 -- 否 --> I3[记录 display_status=ssd1315_missing
主程序告警后继续]
    I2 --> J[display_lvgl_start]
    I3 --> J
    J --> J1[lv_init 和 system_menu_init]
    J1 --> J2[创建 128x64 LVGL display
绑定 flush 回调]
    J2 --> J3[display_ui_build
构建状态栏/标题/4行/页脚]
    J3 --> J4[启动 5ms LVGL tick timer]
    J4 --> J5[创建 display_lvgl_task
20ms 周期刷新 UI]
    J5 --> J6[设置当前 UART 波特率到显示状态]
    J6 --> K{CONFIG_ENABLE_WIFI?}
    K -- 是 --> K1[web_static_init
挂载 SPIFFS storage 分区]
    K1 --> K2[wifi_manager_init]
    K2 --> K3[创建默认 AP/STA netif
AP DHCP 不发布网关/DNS]
    K3 --> K4[esp_wifi_init
注册 STA_DISCONNECTED / GOT_IP 事件]
    K4 --> K5[创建 STA 连接超时回退 timer]
    K5 --> K6[从 NVS 读取 STA 配置
若无则使用默认 STA 配置]
    K6 --> K7[生成 AP SSID: ESP32-S3_AP_XXXX]
    K7 --> K8{有 STA 配置且允许开机 STA?}
    K8 -- 是 --> K9[请求 SYSTEM_NET_STA
启动 APSTA 并连接外部 WiFi]
    K8 -- 否 --> K10[请求 SYSTEM_NET_AP
启动 SoftAP]
    K9 --> K11[start_webserver]
    K10 --> K11
    K -- 否 --> L{CONFIG_ENABLE_BLE
且 CONFIG_BLE_START_ON_BOOT?}
    K11 --> K12[wifi_transport_init
创建 WS 发送队列/静态帧池/发送任务]
    K12 --> K13[httpd_start
端口 80, wildcard 匹配, 96 handlers]
    K13 --> K14[注册 web_api handlers
/api/...]
    K14 --> K15[注册 WebSocket
/ws]
    K15 --> K16[注册 web_static handlers
Excel API 和 /* 静态文件]
    K16 --> L
    L -- 是 --> L1[ble_spp_transport_start]
    L1 --> L2[nimble_port_init]
    L2 --> L3[初始化 GAP/GATT
SPP UUID 0xABF0/0xABF1]
    L3 --> L4[创建 NimBLE host task]
    L4 --> L5[BLE sync 后设置设备名并开始广播]
    L -- 否 --> M[health_reporter_start]
    L5 --> M
    M --> M1[创建 health_report_task
每 30 秒或错误变化输出 HEALTH OK/ALERT]
    M1 --> N[打印固件配置日志]
    N --> O([app_main 返回
各 FreeRTOS 任务持续运行])

2. 模块关系总图

文件：06_module_relationship.mmd

flowchart LR
    subgraph App[应用入口 main.c]
        MAIN[app_main
初始化顺序和回调装配]
        CALLBACKS[应用回调
UART/BLE/WiFi/Web API/UI]
    end
    subgraph Core[核心状态]
        APP[app_core
comm_mode + uart_baud]
        STATS[comm_stats
全局通信计数]
        HEALTH[health_reporter
串口健康日志]
    end
    subgraph DataPlane[数据面 Transport + Router]
        UART[uart_transport
UART1 驱动/组帧/写串口]
        ROUTER[router_service
UART 帧路由到 BLE 或 WiFi]
        BLE[ble_transport
NimBLE SPP GATT/Notify]
        WST[wifi_transport
WebSocket RX/TX/发送队列]
    end
    subgraph ControlPlane[控制面 HTTP/文件/WiFi]
        WFM[wifi_manager
AP/STA/NVS/事件/回退]
        API[web_api
/api 控制接口]
        STATIC[web_static
SPIFFS 静态页面和 Excel 文件]
        HTTP[http_utils
JSON/CORS/OPTIONS]
        MOTOR[motor_diag
电机诊断帧和参数表]
    end
    subgraph UI[屏幕和菜单]
        UIC[ui_controller
菜单动作协调]
        MENU[system_menu
菜单状态机]
        LVGL[display_lvgl
状态缓存/LVGL 任务]
        DUI[display_ui
128x64 UI 布局]
        DPORT[display_port
framebuffer/SSD1315 I2C]
    end

    WST -- WebSocket RX --> CALLBACKS

    API --> HTTP
    API --> MOTOR

    WFM -- 状态回调 --> MENU
    WFM -- 状态回调 --> LVGL

    UIC --> LVGL

其他详细流程图

为避免这个 HTML 过大，完整详细图请打开或导入同目录这些 Mermaid 文件：

  • 02_data_plane.mmd：UART/BLE/WiFi 双向透传数据流。
  • 03_wifi_ble_state.mmd：WiFi AP/STA 和 BLE SPP 状态机。
  • 04_http_control_plane.mmd：HTTP API、静态文件、Excel、电机诊断控制流。
  • 05_display_health_stats.mmd：OLED 显示、菜单、统计、健康报告流。
