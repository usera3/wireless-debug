**通信协议文档**

本文档描述上位机软件进行参数读写以及示波时所用的通讯协议。参数读写协议为 Modbus RTU 协议，示波相关的协议为自定义协议。

---

## 1. Modbus RTU

### 1.1 Modbus RTU 通信帧结构

| 用途     | 长度           | 描述                                     |
| -------- | -------------- | ---------------------------------------- |
| 设备地址 | 1 byte         | 从机有唯一的地址                         |
| 功能码   | 1 byte         | 主机要求从机执行的操作类型               |
| 数据     | 可变(0~252 byte) | 包含命令的具体参数，格式和长度取决于功能码 |
| CRC 校验  | 2 byte         | 检查数据在传输过程中是否有错误           |

### 1.2 上位机所用 Modbus RTU 功能码

| 功能码 | 名称             | 操作数据类型         | 作用                                         |
| ------ | ---------------- | -------------------- | -------------------------------------------- |
| 0x03   | 读保持寄存器     | 整型、浮点型、字符型 | 在一个或多个保持寄存器中取得当前的二进制值   |
| 0x06   | 写单个保持寄存器 | 整型、浮点型、字符型 | 把具体二进制值装入一个保持寄存器             |
| 0x10   | 写多个保持寄存器 | 整型、浮点型、字符型 | 把具体的二进制值装入一串连续的保持寄存器     |

### 1.3 功能码 0x03 — 读保持寄存器

**作用**：读从机保持寄存器，字节操作，可读单个或多个。

**发送指令**：从机地址 `0xFF`，寄存器起始地址 `0x2001`，共读取 1 个寄存器。

| 从机地址 | 功能码 | 起始地址(高) | 起始地址(低) | 寄存器数量(高) | 寄存器数量(低) | CRC 高位 | CRC 低位 |
| -------- | ------ | ------------ | ------------ | -------------- | -------------- | -------- | -------- |
| 0xFF     | 0x03   | 0x20         | 0x01         | 0x00           | 0x01           | 0xCB     | 0xD4     |

**响应**：返回寄存器数据。

| 从机地址 | 功能码 | 返回字节数 | 数据(高) | 数据(低) | CRC 高位 | CRC 低位 |
| -------- | ------ | ---------- | -------- | -------- | -------- | -------- |
| 0xFF     | 0x03   | 0x02       | 0x00     | 0x00     | 0x76     | 0x74     |

### 1.4 功能码 0x06 — 写单个保持寄存器

**作用**：写单个保持寄存器，字节操作，只能写一个。

**发送指令**：从机地址 `0xFF`，寄存器地址 `0x0017`，写入值 `0x2193`。

| 从机地址 | 功能码 | 起始地址(高) | 起始地址(低) | 数据(高) | 数据(低) | CRC 高位 | CRC 低位 |
| -------- | ------ | ------------ | ------------ | -------- | -------- | -------- | -------- |
| 0xFF     | 0x06   | 0x00         | 0x17         | 0x21     | 0x93     | 0x61     | 0xF3     |

**响应**：与发送指令相同。

### 1.5 功能码 0x10 — 写多个保持寄存器

**作用**：写多个保持寄存器，字节操作，可写多个。

**发送指令**：从机地址 `0xFF`，寄存器起始地址 `0x0012`，写 2 个寄存器（共 4 字节数据）。

| 从机地址 | 功能码 | 起始地址(高) | 起始地址(低) | 寄存器数量(高) | 寄存器数量(低) | 字节数 | 数据1(高) | 数据1(低) | 数据2(高) | 数据2(低) | CRC 高位 | CRC 低位 |
| -------- | ------ | ------------ | ------------ | -------------- | -------------- | ------ | --------- | --------- | --------- | --------- | -------- | -------- |
| 0xFF     | 0x10   | 0x00         | 0x12         | 0x00           | 0x02           | 0x04   | 0x00      | 0x13      | 0x00      | 0x11      | 0x42     | 0xB3     |

**响应**：

| 从机地址 | 功能码 | 起始地址(高) | 起始地址(低) | 寄存器数量(高) | 寄存器数量(低) | 字节数 | CRC 高位 | CRC 低位 |
| -------- | ------ | ------------ | ------------ | -------------- | -------------- | ------ | -------- | -------- |
| 0xFF     | 0x10   | 0x00         | 0x12         | 0x00           | 0x02           | 0x04   | 0x0C     | 0x8B     |

## 2. 示波相关协议

### 2.1 查询最大通道数 — 功能码 0x04

**作用**：查询下位机最大支持的通道数量。配置通道时，若通道数量超过该上限则进行提示并终止示波。

> 注：功能码 `0x04` 为读输入寄存器，通过不同的寄存器地址区分子命令，详见下方各节。

**发送指令**：读输入寄存器，寄存器地址 `0x0001`，读取 1 个寄存器。

| 从机地址 | 功能码 | 填充位（4 字节）        | CRC 高位 | CRC 低位 |
| -------- | ------ | ----------------------- | -------- | -------- |
| 0xFF     | 0x04   | 0x00 0x01 0x00 0x01     | 0x75     | 0xD4     |

**响应**：

| 从机地址 | 功能码 | 数据长度 | 通道上限           | CRC 高位 | CRC 低位 |
| -------- | ------ | -------- | ------------------ | -------- | -------- |
| 0xFF     | 0x04   | 0x02     | 0x00 0x0C（12）   | 0x90     | 0xE1     |

### 2.2 查询示波帧长 — 功能码 0x04

**作用**：在通道配置前确定示波帧长（默认 130 字节，含 4 字节帧头 + 数据区 + 2 字节 CRC + 4 字节帧尾）。后续示波线程按照此长度对数据进行分帧和校验。

> 帧长由 `LWMB_OSC_BUFFER_SIZE_NO_LEN` 计算得出：`头(4) + 数据区(120) + CRC(2) + 尾(4) = 130`。

**发送指令**：读输入寄存器，寄存器地址 `0x0000`，读取 1 个寄存器。

| 从机地址 | 功能码 | 填充位（4 字节）        | CRC 高位 | CRC 低位 |
| -------- | ------ | ----------------------- | -------- | -------- |
| 0xFF     | 0x04   | 0x00 0x00 0x00 0x01     | 0x24     | 0x14     |

**响应**：

| 从机地址 | 功能码 | 数据长度 | 示波帧长           | CRC 高位 | CRC 低位 |
| -------- | ------ | -------- | ------------------ | -------- | -------- |
| 0xFF     | 0x04   | 0x02     | 0x00 0x82（130）  | 0x90     | 0xE1     |

### 2.3 设置示波通道 — 功能码 0x75

**作用**：示波前进行数据通道的配置，示波将数据读取到对应通道。通道编号范围为 1～6，有几个通道就发送几次该指令。

每条指令的帧格式如下（以通道 1 为例）：

| 从机地址 | 功能码 | 通道编号 | 参数类型 | 变量地址(高 8 位) | 变量地址(低 8 位) | CRC 高位 | CRC 低位 |
| -------- | ------ | -------- | -------- | ----------------- | ----------------- | -------- | -------- |
| 0xFF     | 0x75   | 0x01     | 0x00     | 0x8C              | 0xB6              | 0x7D     | 0x55     |

**参数类型说明**：

| 值   | 类型                        | 占用通道数 |
| ---- | --------------------------- | ---------- |
| 0x00 | 默认（16 位整型）           | 1          |
| 0x01 | 8 位整型（按 16 位传输）    | 1          |
| 0x02 | 16 位整型                   | 1          |
| 0x03 | 32 位整型 / 浮点型          | 2          |
| 0x04 | 64 位整型 / 双精度浮点型    | 4          |

**响应**：与发送指令相同。

### 2.4 查询采样率 — 功能码 0x04

**作用**：上位机读取当前实际采样率（单位：Hz），用于对收到的示波数据进行解析和显示。

**发送指令**：读输入寄存器，寄存器地址 `0x0002`，读取 1 个寄存器。

| 从机地址 | 功能码 | 填充位（4 字节）        | CRC 高位 | CRC 低位 |
| -------- | ------ | ----------------------- | -------- | -------- |
| 0xFF     | 0x04   | 0x00 0x02 0x00 0x01     | 0x85     | 0xD4     |

**响应**：

| 从机地址 | 功能码 | 数据长度 | 采样率                 | CRC 高位 | CRC 低位 |
| -------- | ------ | -------- | ---------------------- | -------- | -------- |
| 0xFF     | 0x04   | 0x02     | 0x17 0x70（6000 Hz）  | 0x9E     | 0xF0     |

> 采样率 = 基准采样率（默认 6000 Hz）/ 采样间隔系数。采样间隔系数由通信速率和通道数自动计算，通道数越多或波特率越低，实际采样率越低。

### 2.5 开始 / 继续示波 — 功能码 0x71

**作用**：启动示波，设备按照规定格式持续向上位机发送示波数据。

**发送指令**：

| 从机地址 | 功能码 | 填充位（4 字节）        | CRC 高位 | CRC 低位 |
| -------- | ------ | ----------------------- | -------- | -------- |
| 0xFF     | 0x71   | 0x00 0x00 0x00 0x00     | 0x68     | 0x1F     |

**响应**：

| 响应帧长 | 从机地址 | 功能码 | 填充位（4 字节）        | CRC 高位 | CRC 低位 |
| -------- | -------- | ------ | ----------------------- | -------- | -------- |
| 0x08     | 0xFF     | 0x71   | 0x00 0x00 0x00 0x00     | 0x68     | 0x1F     |

### 2.6 停止示波 — 功能码 0x72

**作用**：停止示波，通知设备终止数据发送。

**发送指令**：

| 从机地址 | 功能码 | 填充位（4 字节）        | CRC 高位 | CRC 低位 |
| -------- | ------ | ----------------------- | -------- | -------- |
| 0xFF     | 0x72   | 0x00 0x00 0x00 0x00     | 0x2C     | 0x1F     |

**响应**：

| 响应帧长 | 从机地址 | 功能码 | 填充位（4 字节）        | CRC 高位 | CRC 低位 |
| -------- | -------- | ------ | ----------------------- | -------- | -------- |
| 0x08     | 0xFF     | 0x72   | 0x00 0x00 0x00 0x00     | 0x2C     | 0x1F     |

### 2.7 示波心跳 — 功能码 0x08

**作用**：维持示波模式持续运行。设备端若在超时时间内（`LWMB_OSC_HEARTBEAT_TIMEOUT = 3` 秒）未收到来自上位机的心跳包，则自动退出示波模式，停止发送示波数据，并执行必要的清理操作（如降低波特率等）。

> 任何校验合法的数据帧均会重置心跳计时器，并非只有 0x08 帧。

**发送指令**：

| 从机地址 | 功能码 | 填充位（4 字节）        | CRC 高位 | CRC 低位 |
| -------- | ------ | ----------------------- | -------- | -------- |
| 0xFF     | 0x08   | 0x00 0x00 0x00 0x00     | 0xF5     | 0xD5     |

**响应**：

| 响应帧长 | 从机地址 | 功能码 | 填充位（4 字节）        | CRC 高位 | CRC 低位 |
| -------- | -------- | ------ | ----------------------- | -------- | -------- |
| 0x08     | 0xFF     | 0x08   | 0x00 0x00 0x00 0x00     | 0xF5     | 0xD5     |

### 2.8 示波数据帧格式

每帧示波数据由帧头、数据区、CRC 和帧尾四部分组成：

```
FF 77 AA 55 | 数据（120 字节） | CRC（2 字节） | FF 77 AA 55
```

| 字段 | 长度    | 内容                   |
| ---- | ------- | ---------------------- |
| 帧头 | 4 字节  | `FF 77 AA 55`          |
| 数据 | 可变    | 各通道采样数据，大端序 |
| CRC  | 2 字节  | 对数据区的 CRC16 校验  |
| 帧尾 | 4 字节  | `FF 77 AA 55`          |

**通道数据排列规则**：

- 默认/INT8/INT16 类型：每个通道占 **2 字节**（大端序）
- INT32/Float 类型：每个通道占 **4 字节**（大端序）
- INT64/Double 类型：每个通道占 **8 字节**（大端序）

各通道数据在数据区内按通道编号顺序连续排列，达到数据区容量后自动打包发送下一帧。

### 2.9 主动调整采样通信速率 — 功能码 0x73

**作用**：主动设置采样通信速率（单位：bit/秒），设备收到后按照指定速率计算采样率并发送示波数据。

**发送指令**：

| 从机地址 | 功能码 | 速率值（4 字节，大端序） | CRC 高位 | CRC 低位 |
| -------- | ------ | ------------------------ | -------- | -------- |
| 0xFF     | 0x73   | 0x00 0x00 0x00 0x00      | 0xF5     | 0xD5     |

> 速率值为 32 位无符号整数，大端序，单位为 bit/秒。示例中全零表示使用默认速率。

**响应**：与发送指令相同
